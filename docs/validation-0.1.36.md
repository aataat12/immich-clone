# 0.1.36-prototype: target-PC validation

After publication, create and download a backup in 0.1.35, then upgrade using the existing application/data locations. Confirm 0.1.36-prototype and preserved photos/videos, names, tags, AI results and import history.

1. Confirm the extra Photos & videos Home button is gone. Show Hidden Media should become Hide Hidden Media when clicked, then return to the normal library when clicked again. The Show selector and heading should match.
2. Select two or more existing hidden items. Check the selected count, Clear selection, and Select this page. If another hidden page is available, confirm earlier selections stay selected when changing pages. Choose Restore selected to library; only those selections should return to the library, retaining originals and review data. Hide them again if desired.
3. Select hidden items, open Permanently delete selected managed copies and verify the listed names/count. A wrong confirmation should leave deletion disabled. Choose Cancel and confirm nothing was removed. Actual permanent deletion is optional: use only disposable managed copies with available external sources. After typing DELETE and confirming, inspect the completed/pending/failed/not-attempted summary and confirm external sources remain.
4. Leave Hidden Media and reopen it; selection should be cleared. Check People & tags, Bulk import history, Backups, Build Notes, sign-out/unlock and refresh. Try narrow layout if practical.

Return PASS / FAIL / NOT TESTED for each step. No new import, disk-filling or storage-disconnection exercise is needed on your PC. If anything fails, send the action and displayed message and download diagnostics for private review. Final Windows 10 clean-machine/reboot/extended acceptance remains separate.
