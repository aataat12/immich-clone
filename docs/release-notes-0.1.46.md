# Immich Clone 0.1.46 prototype

- Adds three presentation modes to the library: focused gallery browsing, gallery plus inspector-oriented organization, and Guided Purposes.
- Guided Purposes exposes common launch intents—finding media, importing, organizing, reviewing people and tags, recovering hidden items, and protecting/exporting—in short steps that reuse the existing controls and endpoints.
- Existing gallery, albums, favorites, captions, people, tags, batch actions, hidden-media recovery, backups, exports, and diagnostics remain available; this release changes presentation, not catalog semantics.

The prototype installer is unsigned. Keep a verified backup before updating.
