# Immich Clone 0.1.45 prototype

- The People directory shows portraits and counts of distinct visible photos
  and videos for each existing name label. Choose a person to open the matching
  gallery.
- Select two photos to compare them with linked zoom and pan and separate
  favorite controls. The two photos can come from different gallery pages.
- Suggested albums groups visible media into events and possible trips using
  capture timestamps. Review the chronological filmstrip, include adjacent
  media or exclude individual items, and save the selection as a regular album.
  JPEG capture metadata takes priority over filename dates. Videos use
  recognizable filename dates. Location inference remains future work.

The catalog format and original-file handling are the same as in 0.1.44.
Keep a verified backup before updating. This prototype installer is unsigned.
