# 0.1.35-prototype: target-PC validation

Use after the tested installer is published. Create and download a backup in 0.1.34, then install 0.1.35 using the existing application and data locations. Confirm the displayed version and preserved photos/videos, names, tags, AI results and import history.

1. Click Hidden Media. Confirm the heading changes to Hidden Media and a prominent Photos & videos Home button appears. Click Home and confirm normal library items return. Open Hidden Media again, then click Hidden Media a second time; it should return to Library. The Show selector should match each view. Also try Show → Hidden items → Library.
2. Confirm an existing hidden item remains hidden when you leave the view, and restoring it remains an explicit separate action. Its original and review data should remain available.
3. Open Bulk import and confirm existing completed/paused history is accessible. No new import or source-disconnection exercise is required on your PC for this update.
4. Open People & tags, Backups and Build Notes, then sign out and unlock with the existing code. Refresh and confirm normal navigation works. If practical, repeat the Hidden Media return controls in a narrow window.

Return PASS / FAIL / NOT TESTED for each step. If anything fails, provide the action and displayed message; download diagnostics for private review. Do not fill disks, disconnect real storage, force reanalysis or permanently delete personal media for this validation.

This supplements cloud Windows Server checks; final clean-machine, reboot and extended Windows 10 acceptance remain separate.
