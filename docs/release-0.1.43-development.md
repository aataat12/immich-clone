# Release 0.1.43 development record

The three agreed improvements are implemented, accepted and published:

- Clear Date taken / Date imported labels, with capture timezone uncertainty
  explained honestly and original embedded metadata retained.
- Main-gallery search across assigned people, filenames and active tags, with
  result count, Clear, paging and viewer-return context preserved.
- Strong known-person automatic naming from at least two manually confirmed
  independent originals, with uncertainty review, assignment provenance,
  correction/undo and protection against automatic labels training themselves.
