IMMICH CLONE 0.1.3 - EARLY TEST BUILD

This unsigned prototype is not a validated release. Windows Server 2022 testing
does not establish Windows 10 compatibility. Do not bulk-import a real library yet.

It provides loopback-only access-code login, upload of preserved originals,
JPEG/PNG previews and full-image viewing, MP4 browser playback, persistent preview
jobs, browsing, exact original download,
JSON catalog export, and consistent backup/verified restore. JPEG/PNG previews
are limited to 40 megapixels. Uploads are limited to 4 GiB per file. Other formats
are preserved/downloadable but preview failure is shown explicitly. No EXIF
orientation, advanced camera metadata, generated video thumbnails, server-side folder scanning, AI,
mobile clients, remote sharing or LAN access in this build.

The installer needs administrator permission and uses Windows LocalService.
No .NET, PostgreSQL, SDK, Python, Docker, WSL or separate media codec is required.
Select application data outside cloud-sync folders. Uploaded originals are copied
into this managed data directory. The external source library is not scanned,
changed, moved or deleted. Browser-selected folder import copies files only after
a confirmation showing file count and byte total. Relative folder structure is
not retained in this prototype. Online-only selections may download when read;
choose only a small available-offline test folder. Uninstall preserves application data and originals.

Start menu: Open library; View access code. Keep the code and backup ZIP private.
Sessions expire after 12 hours and service restart requires signing in again.
The application emits no telemetry and never uploads a machine report.

Backup download stages a ZIP in the data folder before transferring it, so free
space is needed for the full archive. Large downloads should use a browser, not
load into JavaScript memory. Restore only into a new directory, with the service
stopped: immichclone.exe -mode restore -data NEW_ABSOLUTE_PATH -archive BACKUP_ZIP.
Restored previews regenerate. Catalog schema 1 is checked; unknown versions are
refused. JSON catalog export plus independent originals provides a migration path.

Not yet validated: clean Windows 10 install, full OS reboot, long-running
reliability, physical drive disconnect, antivirus/SmartScreen behavior,
production security review and large-library performance. A real full-disk recovery test passed on a disposable cloud NTFS volume. Current startup-failure
rollback covers schema 1, not future schema migrations.

Installer built with Inno Setup (Jordan Russell and Martijn Laan).
Go/x/sys/bbolt license notices accompany the installed executable.

DIAGNOSTIC BUILD
The app writes private rotating JSON-line diagnostic files under the standard
ProgramData ImmichCloneDiagnostics folder. Each channel retains up to two 4MiB
files (application, offline commands, installer; up to 24MiB total). Events include
UTC time, build version, operation/stage, duration, result/status, transfer byte
counts and error category/native error number. No hardware inventory, OS build,
account/machine names, paths, media names, content hashes, credentials, request
headers/bodies or personal media are logged. No automatic upload occurs.

Use Download diagnostics after signing in, or the Start menu's Export diagnostic
log if the service is unavailable. The exporter lets you save one .log file.
Review and attach it in the private project conversation, not a public issue.
Setup and application data are preserved by uninstall; diagnostic files are also
retained for troubleshooting. Raw Windows/Inno transcripts are not collected.
