Preview support: JPEG, PNG, BMP, GIF first frame and TIFF first page, up to 40 megapixels. BMP/GIF/TIFF encoded files are limited to 64 MiB for previews. TIFF variants may be unsupported; TIFF orientation/metadata and color-managed HDR rendering are not implemented. Other files are preserved and downloadable; their previews show an explicit unsupported status. JPEG previews honor EXIF orientation and read capture date/camera make/model. Missing capture dates use upload date; camera timestamps have no assumed timezone. The optional bundled CPU provider generates H.264/HEVC video and single/grid HEIC previews (up to 40 megapixels, 512 MiB worker commitment limit and 30-second deadline). High-bit-depth/HDR, RAW and broader HEIF variants remain unsupported. HEIC/MOV viewers show the derived preview only. Hide from library removes a card from the main view while keeping its original; use Hidden items to restore it. Duplicate uploads do not automatically unhide items. Preview failure leaves the original downloadable; use Retry preview after resolving a failure. MP4 playback uses your browser’s codecs. Folder import copies selected files into managed storage and leaves the source untouched. Relative folder paths are retained in the catalog and JSON export; duplicates keep each relative source alias. Online-only files may download when read; select only a small, available-offline test folder.

Managed file location
This is the application-managed copy, named by its content hash. Original source locations are not tracked as full paths. Use Download original to save a copy with its original filename.
 

Permanently delete managed copy?
This removes the managed original, previews, faces, names, tags and AI results for this item and all its relative source aliases. External source files, import receipts and existing backups remain. Deleted import receipts cannot resume copying this item; start a new import to copy it again.
This cannot be undone in the gallery. Recovery requires an earlier backup or a new import. Once accepted, interrupted cleanup resumes at startup or through Retry cleanup. New backups are blocked until cleanup finishes.
