People & tags

Review faces, supply names and organize photos. Everything runs on this PC.

AI suggests faces and 80 common object categories. It does not know people's names. Matches can be wrong; assignments require your confirmation. Select faces and apply an existing name to combine groups, or a new name to split them. Clear the name to leave them unidentified. Undo reverses the last name change for each face. AI currently analyzes JPEG, PNG, BMP, the first GIF frame and the first TIFF page, up to 64 MiB / 40 megapixels. Use Not a face to dismiss a detection; the Dismissed faces view lets you restore it with its name intact. Supported 8-bit HEIC analysis uses the bundled media decoder. Videos are analyzed only when you choose Analyze sampled video, at up to 12 evenly spaced positions; timestamps describe sampled coverage, not every frame. Automatic grouping, model reanalysis and every-frame Full Scan remain unavailable. Original files stay unchanged.
