How suggestions, names and supported media work
AI matches faces and suggests 80 common object categories. Supply names for known people. When automatic naming is enabled, strong matches can be assigned after analysis; uncertain matches need confirmation. Matches can be wrong, so review and correct names. Select faces and apply an existing name to combine groups, or a new name to split them. Clear the name to leave them unidentified. Undo reverses the last name change for each face. AI currently analyzes JPEG, PNG, BMP, the first GIF frame and the first TIFF page, up to 64 MiB / 40 megapixels. Use Not a face to dismiss a detection; the Dismissed faces view lets you restore it with its name intact. Supported 8-bit HEIC analysis uses the bundled media decoder. Videos are analyzed only when you choose Analyze sampled video, at up to 12 evenly spaced positions; timestamps describe sampled coverage, not every frame. Review-first additive reanalysis is available for completed supported media. Automatic naming requires manually confirmed faces from at least two different originals for the same person. Automatic names are marked and can be corrected or undone. They become recognition references only after you confirm them. Every-frame Full Scan remains unavailable. Original files stay unchanged.

Bulk local AI analysis

Analyze all currently visible, unprocessed supported photos (including supported 8-bit HEIC) across the library, regardless of the search or page. Completed, failed, already queued, hidden, oversized and unsupported items are skipped. New imports need another batch. Pause/cancel stops starting this batch’s remaining photos; an in-progress photo may finish. Cancel keeps results and returns pending photos to not_requested. Individual jobs are unaffected. Active bulk import takes priority.
