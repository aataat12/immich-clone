How to restore a backup
Restore is an offline maintenance command. It creates a new library folder; it does not replace or switch your installed library.
  1. Wait for Ready, download the verified ZIP and its recovery instructions, and keep both on separate storage. The instructions record the expected archive SHA256; compare it with the downloaded ZIP before restoring.
  2. Use the installed executable from the same version. Choose a local destination outside cloud-sync folders, with an existing parent and enough free space. The destination folder itself must not exist.
  3. Stop the ImmichClone service during the maintenance window. In PowerShell, run the restore command shown in the downloaded instructions, replacing all example paths. Check its exit code before running verification.
  4. Verify the restored originals. Restart the original service afterward; it still uses the original library. Activating the recovered library is a separate operation.
If a command fails, keep the archive and existing library. Do not copy partial restoration files into the live library or blindly delete a target. Ctrl+C requests cancellation; wait for cleanup before a fresh retry.
Instructions work offline and contain the expected checksum, not your access code. Keep the ZIP private: it contains the access code and originals. Downloading instructions alone does not create, download or test a backup.
